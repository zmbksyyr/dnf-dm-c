# DNF GM

DNF 私服（服务端）的 GM 工具。C语言编写，Windows 原生界面，单文件 exe，不依赖任何运行时或第三方库——MySQL 协议、PVF 解析、zlib 解压都是自带实现。

## 能做什么

- **角色**：等级、职业/觉醒、金币、复活币、点券、SP/TP、QP、疲劳、PVP 段位、改名
- **物品**：直接编辑 6 个容器（物品栏 / 穿戴 / 宠物 / 仓库 / 珠宝 / 账号金库）；按编号或名称查询、批量发放；扫描并清除错误物品
- **连续取码**：发放页的开关（默认开启，也可用热键）。开着之后持续读游戏里鼠标悬停的物品，自动整行追加到发放队列，已有的编号自动跳过——回游戏逐件悬停，回来就是一份攒好的清单，直接邮件发放或入包
- **邮件**：收发、删除、附件
- **宠物 / 时装**：编辑列表，清理表内错误记录
- **任务**：放弃、标记完成、补发材料、清空
- **活动 / 封停**：活动启停、封停解封、重置密码
- **泡点**：GM 页里开关，按设定间隔给每个在线账号加赠送点券（只在工具开着时结算）
- **备份**：整库或单角色导出 SQL，可还原
- **PVF**：只读解析，显示真实物品名（不加载也能用，只是名字显示成 `#12345`）

本地编译与回归脚本见 [`tools/README.md`](tools/README.md)。
