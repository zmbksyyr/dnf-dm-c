# DNF GM

DNF 私服（服务端）的 GM 工具。C 语言，Windows 原生界面，单个 exe，不依赖运行时或第三方库：
MySQL 协议、PVF 解析、zlib 解压均为自带实现。

## 功能

- **角色**：等级、职业/觉醒、金币、复活币、点券、SP/TP、QP、疲劳、PVP 段位、改名、克隆
- **物品**：编辑 6 个容器（物品栏 / 穿戴 / 宠物 / 仓库 / 珠宝 / 账号金库）；按编号或名称查询、批量发放；扫描并清除错误物品
- **连续取码**：读游戏内鼠标悬停的物品编号，自动整行追加到发放队列（默认开启，也可用热键）
- **邮件**：收发、删除、附件
- **宠物 / 时装**：编辑列表，清理无效记录
- **任务**：放弃、标记完成、补发材料、清空
- **活动 / 封停**：活动启停、封停解封、重置密码
- **泡点**：按间隔给在线账号发点券 / D 点 / D 币 / 物品，可限定人群与时长
- **备份**：整库或单角色导出 SQL，可还原；长任务有模态进度窗（可取消、可转后台；工具栏不再单独占一个取消按钮），
  还原前自动整库备份；取消或失败时回滚当前事务。DDL 与 MyISAM 写入不支持整体回滚
- **PVF**：只读解析，显示真实物品名（未加载时显示为 `#编号`）

在线金币、复活币、补满疲劳、SP/TP、QP、装备栏、装备等级、负重上限和角色等级支持 Native 与原版 Linux 的同一游戏端桥接：修改游戏内存、推送客户端，
确认原游戏存档后才报成功；快捷增加按实际余额递增。金币超过原游戏的等级／PVF 上限时拒绝，
不截断发放；数值上限为 2147483647。其他缓存角色数值仍需退出游戏。
GM 独立连接 MySQL，可选的 DP2 模块由 GM 自带，
在“关于 → 桥接”查看步骤，一并导出脚本、配置和说明；也可阅读[桥接说明](docs/bridge.md)。
Linux 与 Windows 兼容宿主使用相同的模块和配置方式。
GM 自动检测账号所在频道的有效心跳与各项能力，支持的操作自动走在线桥接；
其余项目置灰并提示退出游戏后修改，不会退回直接改在线角色的数据库。
金币使用独立 v2 队列，疲劳使用 v3，SP/TP 使用 v4，QP 使用 v5，装备栏与装备等级共用 v7，负重使用 v8，角色等级使用 v9；升级时须同时更新 GM 与游戏端 helper，旧版桥接不能处理新增操作。
疲劳按游戏原接口读取的基础与额外上限补满，清除已使用计数；离线按角色上限补满基础疲劳并保留额外疲劳。
固定原 ELF 的 `charac_stat.fatigue` 是剩余疲劳；旧实现清零的判断有误，现已修正。
“满 SP/TP”设置四组计数为 65535，在线调用原技能通知和存档接口，保留已学技能与技能指令。
原协议每组只有 16 位，旧值 90000 实际传成 24464；在线与离线均拒绝超出 0..65535 的输入。
QP 的原通知使用 32 位，继续保留“满 QP”90000 的目标。在线与离线支持 0..2147483647，
保留已购买属性、重置次数与任务碎片；离线懒建记录只允许角色归属、未删除与离线检查全部通过的目标。
装备栏开启两个扩展槽；装备等级按 `[gm] lev_max` 设置（默认 85，范围 1..255），
保留支援兵选择。在线经原游戏设置、通知和保存，离线写入同时核对归属、未删除与离线状态。
“取消负重”将容量设置为固定 99999999，并非无限容量。原按钮此前要求离线，现支持在线通过原属性访问器更新、通知及存档；离线同样核对角色归属、未删除与离线状态，只更新负重字段。
等级输入和“+10”支持在线城镇角色，须先加载匹配的 PVF；经验设为目标等级起始累计值，
由游戏端再次核对曲线。原游戏逐级更新属性、SP/TP 并通知和保存；技能点为负或超过 16 位通知范围时，在修改前拒绝。
存档未确认时先核对当前数据，同等级重试不重复升级事件。离线更新同时检查归属、删除、登录状态和统计行，
两张经验表与处罚清除在同一事务中完成，读回不符或失败均回滚。
职业/觉醒修改仍要求离线；实际写入与幂等确认同时核对账号归属、未删除及登录状态，
防止角色在界面检查后上线，造成数据库与游戏缓存脱节。
转职／觉醒按原游戏编码显示，名称优先取 PVF；只改职业保留原值，未知值不会自动归零。

泡点的在线点券／赠送点券在账单提交后，通过 v6 队列请求原游戏重新加载余额，
核对游戏缓存并发送通知才确认完成。入队失败会回滚本次 SQL；提交后刷新未确认时显示实际入账与未确认数，
停止泡点，不能重发整批。并发奖励按账单实际余额累加，刷新不再发钱。
升级时须同时更新 GM 与游戏端 helper；直接编辑点券的角色表单仍要求离线。

“仅在线”泡点只发给当前游戏角色；登录表残留在线标记或停留在选角界面的账号，
经游戏端确认没有当前角色后跳过，不中断其他玩家发放。桥接故障、超时和不确定结果仍会停止发放。
全服/指定账号复活币如包含在线账号的多个角色，
会在提交前拒绝，需退出该账号或选择仅在线；保存失败、超时等可能产生部分到账，
界面会显示实际结果并停用泡点，核对后再处理，不能直接重发整批。
搜索按钮查询数据库，支持角色编号，不限于首次载入的名单；轮询保留已提交的搜索条件。

## 构建与回归

```
tools\build.bat            # 需要 zig；产物在 ..\_build\DNF_GM_C\
python tools\regress.py    # 回归套件，见 tools\README.md
```

详细说明见 [`tools/README.md`](tools/README.md)。
