# DNF GM

DNF 私服（服务端）的 GM 工具。C 语言，Windows 原生界面，单个 exe，不依赖运行时或第三方库：
MySQL 协议、PVF 解析、zlib 解压均为自带实现。

## 功能

- **角色**：等级、职业/觉醒、金币、复活币、点券、SP/TP、QP、疲劳、PVP 段位、改名、克隆
- **物品**：编辑 6 个容器（物品栏 / 穿戴 / 宠物 / 仓库 / 珠宝 / 账号金库）；按编号或名称查询、批量发放；扫描并清除错误物品
- **连续取码**：读游戏内鼠标悬停的物品编号，自动整行追加到发放队列（默认开启，也可用热键）
- **邮件**：收发、删除、附件
- **宠物 / 时装**：编辑列表，清理无效记录
- **任务**：放弃、标记完成、补发材料、清空
- **活动 / 封停**：活动启停、封停解封、重置密码
- **泡点**：按间隔给在线账号发点券 / D 点 / D 币 / 物品，可限定人群与时长
- **备份**：整库或单角色导出 SQL，可还原；还原前自动整库备份，还原中可取消（整体回滚）
- **PVF**：只读解析，显示真实物品名（未加载时显示为 `#编号`）

## 构建与回归

```
tools\build.bat            # 需要 zig；产物在 ..\_build\DNF_GM_C\
python tools\regress.py    # 回归套件，见 tools\README.md
```

详细说明见 [`tools/README.md`](tools/README.md)。
